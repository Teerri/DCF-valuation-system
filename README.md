# AH 全市场 DCF 估值系统 — 业务设计方案

> 汇报人：庞志桐  
> 日期：2026-05-05  

---

## 1. 系统定位



本项目是一套覆盖 A 股与 H 股全市场的自动化 DCF 估值系统，面向专业投资团队使用。

目前 A 股共有约 5,400 家上市公司，港股约 2,600 家，其中约 155 家企业同时在两地上市（A+H 股）。系统支持全市场数据采集、多层筛选与质检、批量估值计算与信号生成，为每家符合条件的上市公司输出基于 DCF 模型的内在价值与行业内估值信号，支撑投资分析与估值研究。

---

## 2. 系统运行流程

### 第一阶段：全量数据采集

系统首先从两个数据源完整拉取当次所需全部数据，落库后再进行后续工作，确保计算阶段数据完整一致。

**Wind 数据库**：负责财务历史数据：三大财务报表的原始科目数据、当日及历史股价、人民币/港元汇率、行业分类信息。

**朝阳永续数据库**：负责前瞻性数据：各公司分析师一致预期的未来 1～3 年盈利增长率，作为 DCF 预测期增长假设的核心输入。

### 第二阶段：筛选与数据质检

数据落库后，系统对全量标的执行两类筛选和一层数据质量检验。

**金融类公司剔除**：银行、保险、证券等金融机构财务结构特殊，DCF 模型不适用，系统自动识别并跳过。

**亏损公司剔除**：EBIT（息税前利润）为负的企业，DCF 在数学上无法给出有意义的估值，系统对当期或连续亏损企业标记并跳过，同时单独列示。

**数据质检**：财务数据进入计算前接受多项规则检验，识别极端异常（如关键字段缺失、财务比率严重超出正常范围等），未通过检验的标的不参与计算并标记为待人工复核。

### 第三阶段：批量 DCF 估值计算

通过筛选和质检的标的同时并行计算，每家公司独立运行，单家失败不影响其他公司，全市场计算在数小时内完成。计算结果实时写入数据库，支持中途中断后的断点续算。

### 第四阶段：后处理与输出

计算完成后，系统对结果进行两项后处理：

**估值结果质检**：对计算结果本身进行合理性检验，识别并标记异常结果，防止参数问题产生的极端估值干扰决策。

**估值信号生成**：在申万一级行业内对各公司估值偏差进行横截面标准化，生成行业内百分位数和估值信号标签，使不同公司的估值结果可横向比较。

最终生成 Excel 文件，包含四个 Sheet，供使用者查阅与分析。

## 3. 估值方法论

### 3.1 两阶段折现现金流（DCF）模型

**核心逻辑**：企业的内在价值等于其未来能产生的所有自由现金流折算至今日的价值之和。模型分两阶段：

第一阶段（显式预测期，默认 5 年）：基于公司历史财务数据和分析师预期，逐年预测无杠杆自由现金流（FCFF），按折现率（WACC）折算为当前价值。

第二阶段（终值）：预测期结束后，假设公司按永续增长率长期经营，计算其长期价值并折现至今日。

两阶段之和为企业价值，扣除净债务、除以流通股数，得到每股内在价值，与当前市价比较评估高估或低估程度。

### 3.2 财务指标计算的严谨性

本系统的所需的所有关键财务指标（EBIT、折旧与摊销、资本支出、营运资本变化）均从财务报表原始科目在本地重新计算，确保计算口径清晰、严谨。


### 3.3 关键假设参数

| 参数 | 含义 | 设置方式 |
|------|------|----------|
| 折现率（WACC） | 资金机会成本，反映公司风险水平 | 基于国债收益率、市场风险溢价、公司风险系数（Beta）计算 |
| 盈利增长率 | 预测期内息税前利润年增速 | 优先使用朝阳永续一致预期数据，无覆盖时使用行业中位数或默认值 |
| 资本支出增长率 | 维持业务增长所需资本投入的年增速 | 基于历史数据估算 |
| 永续增长率（g） | 终值阶段长期增长假设 | 设有强制上限约束（不超过 WACC-1% 且不超过 4%），防止终值失真 |

### 3.4 中国市场专项适配

**A 股与 H 股双口径处理**：A 股执行中国会计准则，H 股执行国际财务报告准则，两套准则下利润表科目结构不同，系统分别建立字段映射规则，确保同一 DCF 公式在两个市场中取得正确的数据输入。

**折现率**：折现率基于当期国债收益率和公司风险参数计算，A 股参照中债收益率，H 股参照港债收益率。

**AH 汇率处理**：H 股财务数据以人民币列报，股价以港元计价，系统统一在人民币口径下完成估值计算，再按实时汇率换算为港元与港股市价比较，并自动输出 AH 溢价分析。

## 4. 估值信号体系（可选补充）

除每股内在价值的绝对估值结果外，系统在申万一级行业内对所有标的进行横截面标准化处理，补充生成可直接横向比较的估值信号。

**信号标签含义**：

| 信号标签 | 含义 |
|---------|------|
| 深度低估 | 在申万一级行业内折价排名最低的 10% |
| 低估 | 折价排名 10%～30% |
| 中性 | 折价排名 30%～70% |
| 高估 | 折价排名 70%～90% |
| 极度高估 | 折价排名最高的 10% |

估值信号仅反映当前 DCF 框架下的相对估值判断，不代表投资决策建议。

## 5. 数据来源

| 数据类型 | 来源 | 说明 |
|----------|------|------|
| 历史财务报表原始科目 | Wind（万得） | 国内机构投资者行业标准数据平台，覆盖全部 A 股及港股 |
| 当日及历史股价 | Wind | 用于市价比较和 Beta 计算 |
| 人民币/港元汇率 | Wind | 用于 H 股估值换算 |
| 行业分类 | Wind（申万行业） | 用于金融类筛选和信号生成 |
| 分析师一致预期盈利增长率 | 朝阳永续 | 国内分析师一致预期数据行业标准，市场占有率超 90% |

## 6. 系统输出

### 6.1 Excel 文件（每次运行生成一份）

文件以运行日期命名（如 `dcf_20260504.xlsx`），包含四个 Sheet：

**Sheet 1：筛选结果**
列示本次被剔除、未进入估值计算的全部标的及原因（金融类公司、亏损公司），供使用者了解覆盖范围。

**Sheet 2：质检结果**
列示通过筛选但因财务数据异常未通过质检的标的及触发规则，供使用者判断是否需要人工处理。

**Sheet 3：DCF 估值结果**
全量估值结果，每家公司输出：每股内在价值（含 H 股港元/人民币双口径）、企业价值与权益价值、当日市价与折溢价率、使用的假设参数、AH 溢价率（仅两地上市公司）、关键中间计算量（EBIT、税率、D&A、CapEx）便于核验。

**Sheet 4：估值信号**
仅包含估值结果正常的标的，输出行业内 Z-score、行业内百分位数、估值信号标签，支持直接按信号筛选投资标的。

### 6.2 数据库存储

所有估值结果同时写入 MySQL 数据库，支持：历史查询（某只股票过去数期的估值变化）、AH 溢价历史分位数计算、全市场汇总统计。

## 7. 适用场景

**历史估值回溯**：利用数据库历史结果，观察某只股票的 DCF 估值走势与历史股价的对比关系。

**全市场低估标的筛选**：运行完成后，通过 Sheet 4 按信号标签筛选"深度低估"标的，快速定位当前市场中在各行业内相对低估的公司。

**行业横向比较**：在同一行业内对比各公司的折溢价率和信号标签，识别行业内相对高估与低估标的。

**AH 两地比较**：对于同时在 A 股和 H 股上市的公司，对比两市折溢价率与 AH 溢价率，辅助判断两地相对投资价值。

---

## 8. 局限性说明

**模型对假设参数敏感**：折现率与增长率的变化对估值结果影响较大，系统输出为基准假设下的单点估值，建议结合参数敏感性理解估值区间而非单点结论。

**不覆盖金融类和亏损企业**：银行、保险、证券等金融类公司及 EBIT 持续为负的亏损企业不在计算范围内。

**无法反映定性因素**：管理层变动、政策冲击、行业格局突变等定性因素不体现于历史财务数据，DCF 模型无法自动捕捉。

**依赖财务数据质量**：系统设有多层数据质检，但估值准确性最终取决于上市公司的信息披露质量。
